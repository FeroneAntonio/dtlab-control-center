# Changelog

- dashboard OT ticket-first con Streamlit e interfaccia alternativa Next.js;
- API FastAPI con RBAC fail-closed e token esclusivamente runtime;
- raccolta read-only Cisco Cyber Vision e VMware con snapshot verificati;
- topologia OT, Asset 360, rischio, vulnerabilità, baseline ed evidenze;
- audit endpoint PLC per scritture locali non osservabili tramite SPAN/TAP;
- deduplicazione degli episodi, spool limitato e retention degli snapshot;
- ticketing persistente con operatori, SLA, orari aziendali e audit trail;
- export JSON, CSV, CEF/NDJSON e predisposizione Syslog/SIEM;
- regole Cyber Vision per gli scenari Modbus noti e le funzioni generiche;
- bundle aziendale BeerFactory completo e launcher di test limitato nel tempo;
- deploy autonomo sulla VM Ubuntu con systemd, staging e rollback;
- documentazione tecnica, runbook, demo commissione e CI multipiattaforma.
